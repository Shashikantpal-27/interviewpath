InterviewPath AI

AI-powered interview preparation platform that helps students prepare for company-wise and role-wise interviews with structured roadmaps, interview topics, and mock practice.

🚀 Features
Company-wise & role-wise preparation
Interview round-wise roadmap
Technical & HR preparation
Mock interview practice
Personalized feedback
JWT authentication
🛠️ Tech Stack

Frontend: React.js, Tailwind CSS, Vite
Backend: Node.js, Express.js
Database: MongoDB
Authentication: JWT
Tools: Git, GitHub, Postman

🌐 Live Project

👉 https://interviewpath-one.varcel.app/
📌 Project

Developed as a capstone project to provide students with a structured and easy-to-use interview preparation platform.
